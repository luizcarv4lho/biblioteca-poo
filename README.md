# Biblioteca POO

Esse projeto foi desenvolvido em Pyhon, utilizando Programação Orientada a Objetos.

## Funcionalidade implementadas

- Cadastro de livros
- Busca de livros
- Empréstimo de livros
- Devolução de livros
- Persistência em JSON

## Tecnologias utilizadas

- Python
- JSON
- Programação Orientada a Objetos
- Type Hints

## Estrutura do projeto

biblioteca-poo/ --->livro.py--->biblioteca.py--->main.py

## Como executar

`python main.py`
